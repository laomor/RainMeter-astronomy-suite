事件追踪

EVENT TRACKER · 现在固定在左起第 60 像素，事件向右边排队
1 秒 =
把鼠标放到右上角的 S / M（或者太阳、月亮本身）上，画面就切去看太阳、月亮那五个事件的时刻。
这一版量的是事件，不是位置。现在的时刻钉死在一条竖列上（左起第 60 像素），天体只在这一列里上下浮；真正横向走出去的是事件——从右边进来，经过那一列，再往左退场。
窗口取 48 小时（480 秒一像素，铺满 360px），并且让「现在」左边只留 8 小时：过去的部分够交代刚才发生过什么，剩下的全留给还没到的。每个天体只列五个事件——一个刚过去的、四个接下来的——是故意的，铺满整段就成了日历，眼睛没处落。
底边两端写的是窗口的起止，跨了两天，所以只写钟点、不写日期。
参数：420×256 的画板、IconSize 21、Length 360、SecondPerPixel 480、TimeOffsetInPixels 60、OffsetValue 15。
